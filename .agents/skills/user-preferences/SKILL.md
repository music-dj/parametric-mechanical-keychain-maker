# User Preferences & Workflow Rules

When working in this project, always adhere to the following rules:

1. **Green Light for Actions**: Do not ask for permissions before running terminal commands, editing files, or installing packages. The user has given a "green light" for these actions. Proactively execute the code and scripts on behalf of the user.
2. **Major Changes & Suggestions**: If you have suggestions or want to make major/large changes to the project's structure, logic, or features, you **must ask the user first** before implementing them.
3. **Communication**: Keep the user informed about the specific adjustments and modifications you have made so they can easily find them.
4. **UI Design**: Keep the interface modern and beautiful.
